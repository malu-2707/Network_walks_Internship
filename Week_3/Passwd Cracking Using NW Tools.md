# Password Cracking Using Networkwalks Tools

## Project Overview

This project demonstrates password recovery from encrypted PDF documents using free online cybersecurity tools developed by **Networkwalks**.

The lab uses two browser-based tools:

1. **Networkwalks Hash Calculator** – Extracts password hashes from protected PDF documents.
2. **Networkwalks Password Cracker** – Attempts to recover the original password from the extracted hash.

The exercise provides practical exposure to password hash extraction, dictionary-based password attacks, and document security without requiring additional software installation.

## Objectives

- Understand the fundamentals of password cracking.
- Learn how password hashes are extracted from encrypted PDF files.
- Explore Networkwalks online cybersecurity tools.
- Perform password recovery using extracted PDF hashes.
- Verify recovered passwords by opening protected PDF documents.
- Understand the importance of strong password protection.

## Methodology

### Step 1 – Obtain the Encrypted PDF

Downloaded the password-protected PDF documents provided for the cybersecurity lab.

### Step 2 – Extract the PDF Hash

Opened the Networkwalks Hash Calculator and uploaded the encrypted PDF document.

The tool extracted the password hash in PDF format, beginning with `$pdf$`.

### Step 3 – Copy the Extracted Hash

Copied the complete hash value generated by the Hash Calculator.

### Step 4 – Perform Password Cracking

Opened the Networkwalks Password Cracker and pasted the extracted PDF hash.

Started the password recovery process and waited for the tool to identify a matching password.

### Step 5 – Verify the Recovered Password

Used the recovered password to open the corresponding encrypted PDF document and verified successful access.

## Results – Password Recovery

## Security Recommendations

- Use long and complex passwords.
- Avoid dictionary words and predictable password patterns.
- Never reuse passwords across multiple accounts or documents.
- Use password managers to generate and securely store passwords.
- Protect confidential PDF documents using strong encryption and unique passwords.
