# Week 02 – Footprinting & Network Scanning

## Objective
To understand practical cybersecurity reconnaissance techniques through Google Dorking and network scanning using Zenmap.

## Modules Completed
- **W2-PM2:** GHDB-Based Footprinting Attacks (Google Dorking)
- **W2-PM5:** Zenmap-Based Network Scanning

## 1. W2-PM2 – Google Dorking

**Tools Used:** Google Search, Google Hacking Database (GHDB)

**Methodology:**
- Used Google search operators such as `filetype:pdf`, `site:`, `intitle:`, and `inurl:`.
- Searched for publicly accessible mathematics textbooks and educational resources.
- Identified and documented relevant PDF resources.

**Result:** Successfully identified publicly accessible mathematics textbooks and educational PDF resources.

## 2. W2-PM5 – Network Scanning with Zenmap

**Tools Used:** Zenmap, Nmap, Windows CMD, Kali Linux Terminal.

**Methodology:**
- Installed Zenmap on Windows.
- Identified the local IP address and LAN subnet.
- Performed a Ping Scan to discover live hosts.
- Identified available IP and MAC addresses.
- Generated network topology and saved it as a PDF.

**Result:** Successfully discovered live hosts and generated a graphical network topology.

## Learning Outcomes
- Understanding Google Dorking and GHDB techniques.
- Identifying publicly indexed information.
- Performing network host discovery.
- Understanding IP addresses, MAC addresses, and LAN subnets.
- Visualizing network topology using Zenmap.

## Conclusion
Successfully completed both selected Week 02 modules, gaining practical knowledge of information gathering, digital footprinting, and network reconnaissance.
